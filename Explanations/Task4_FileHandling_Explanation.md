# Task 4: File Handling — Student Records

### Objective

To store student information in a text file, read it back, and display its contents.

### Concept

Java file handling allows programs to create, write, and read files. Classes such as `FileWriter`, `BufferedWriter`, `FileReader`, and `BufferedReader` support text-file operations.

### Working

The program writes a student's ID, name, course, and marks to `students.txt`. It then reads the file line by line and displays the saved information in the console. Exception handling manages errors that may occur during file operations.

### Concepts Used

- File handling
- `FileWriter` and `BufferedWriter`
- `FileReader` and `BufferedReader`
- `try-catch`
- `IOException`
- Try-with-resources
