# Task 2: Interface — Payment System

### Objective

To demonstrate how Java interfaces allow different classes to implement common methods in their own ways.

### Concept

An interface defines a set of methods that implementing classes must provide. The `implements` keyword is used to implement an interface.

### Working

The `Payment` interface declares the `pay()` and `showPaymentDetails()` methods. The `UPIPayment` and `CardPayment` classes implement these methods with different payment-related messages. The main method creates objects of both classes and demonstrates their functionality.

### Concepts Used

- Interfaces
- `implements` keyword
- Method implementation
- Classes and objects
- Polymorphism
