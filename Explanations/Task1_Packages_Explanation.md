# Task 1: Packages — Organizing Java Code

## Objective

To create a custom Java package and access its class from another Java file.

## Concept

A package in Java groups related classes and helps organize code. The `package` keyword declares a package, while the `import` keyword allows a class from another package to be used.

## Working

A custom package named `studentmanagement` contains the `Student` class, which stores a student's ID, name, and course. The `Main` class imports `Student`, creates an object, and displays the student's information.

## Concepts Used

- Custom packages
- `package` and `import` keywords
- Classes and objects
- Constructors and methods
